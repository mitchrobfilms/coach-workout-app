# Watching GLP1 Life classes on a TV

| TV / device | 📺 Cast (Chrome on Android / PC / Mac) | AirPlay (iPhone/iPad/Mac Safari) | TV browser `?tv=1` big-screen mode |
|---|---|---|---|
| **Chromecast / Google TV** (stick, or TVs with Google TV / Chromecast built-in: Sony, TCL, Hisense, Philips) | ✅ Works — class video plays on the TV, phone keeps camera + coaching | ❌ | Google TV has no proper web browser |
| **Sky Glass** (Gen 2 / Air) | ❌ No Google Cast built in. Works if you plug a Chromecast into HDMI | ✅ AirPlay added in a 2025 software update (iPhone/iPad/Mac) | ❌ No web browser |
| **Fire TV** (stick / Fire TV Edition TVs) | ❌ No Google Cast support | ❌ (only via 3rd-party apps) | ✅ Open in the **Silk** browser |
| **Samsung** (Tizen 2018+) | ❌ Not built in (only with a Chromecast plugged in) | ✅ Most 2018+ models support AirPlay 2 | ✅ Samsung Internet browser |
| **LG** (webOS 2018+) | ❌ Not built in | ✅ Most 2018+ models support AirPlay 2 | ✅ LG Web Browser |
| **Apple TV** | ❌ | ✅ | ❌ |

Notes
- Google Cast from a web page only works in **Chrome** (Android, Windows, Mac, ChromeOS). iPhone browsers can't use Google Cast — use AirPlay from Safari, or TV mode.
- We cast with the Google **Default Media Receiver** (no Cast developer registration needed). It plays each move's clip on repeat and follows the class as moves change; the music, voice coaching and rep counting stay on the phone.
- TV mode (`https://glp1life.co.uk/?tv=1`) uses big text, hides the bottom bar and camera self-view, and supports remote-control arrow keys. Most TVs have no camera, so coaching feedback is off; the class still runs with the trainer video, timer and voice.
- Screen mirroring (Android "Smart View"/"Cast screen", iPhone Screen Mirroring) also works on any TV that supports it.
